# Aurora Extract 0.5.1: update notes (do NOT submit until the owner approves)

**What's new:**
- A run now happens in a small window of its own that closes by itself when the run finishes. While the run is going, the small window must stay open and not minimized or fully covered.
- Instagram followers/following: waits for the pop-up to finish loading and closes a leftover different pop-up first.
- Clearer message when the page window is hidden.
